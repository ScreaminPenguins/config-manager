# dotfiles

My dotfiles

Configurations for:

- nvim
- tmux
- tmux-powerline
- k9s
- starship
- zsh
- git-templates
- gitui
- kitty

Contains Custom Scripts:

- tmux-sessionizer
  - Script to quickly find & switch projects using TMUX as a session manager
- gcloud-switch
  - Script to update `gcloud` configurations based on alias

Also contains a script `init/setup.sh` to help ease the pain of installing/setting up everything
